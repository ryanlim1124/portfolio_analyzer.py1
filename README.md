# Portfolio Analyzer
A Python tool that pulls live and historical market data via `yfinance` and analyzes the performance, risk, and composition of an investment portfolio.

## Why I built this
I'm a Business & Financial Technology student with a focus on fintech and self-directed investing. I wanted a hands-on way to actually apply portfolio theory — return, risk, diversification — using real market data instead of just reading about it in a textbook. This project was my way of connecting the Python side of my coursework to the finance side.

## What it does
* Pulls historical price data for a list of tickers
* Calculates portfolio-level metrics such as total return, volatility, and allocation weights
* Sharpe ratio, correlation matrix, cumulative return plot

## Tech stack
* Python
* yfinance
* pandas / numpy
* matplotlib
